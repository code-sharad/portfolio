# Invoice Management System

A full-stack invoice management platform for small businesses — simplifying accounting and inventory tracking in one place.

## Overview

Small businesses juggle invoicing, inventory, and tax calculations across disconnected tools. This system brings them together: real-time inventory updates, product search and categorization, invoice generation, and automated tax calculations.

Built with React, Express, and MongoDB, and deployed on Google Cloud Platform using Docker for containerization.

## Key Features

- **Real-Time Inventory Updates** – Stock levels stay in sync as invoices are created
- **Product Search & Categorization** – Organize and find products quickly
- **Invoice Generation** – Create professional invoices in a few clicks
- **Automated Tax Calculations** – Taxes computed per line item, no manual math
- **Dockerized Deployment** – Containerized and deployed on GCP for reproducible releases

## Tech Stack

- **Frontend**: React.js, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Infrastructure**: Docker, Google Cloud Platform

# Portfolio

Personal portfolio and blog of Sharad Bhadait — live at **[iamsharad.in](https://iamsharad.in)**.

Built with [Next.js](https://nextjs.org) (App Router), TypeScript, Tailwind CSS, and an MDX-driven content pipeline.

## Getting Started

Requires Node.js 20.9+ and pnpm.

```bash
git clone https://github.com/code-sharad/portfolio.git
cd portfolio
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

Deployed on [Vercel](https://vercel.com). Pushing to `main` triggers a production deploy.
